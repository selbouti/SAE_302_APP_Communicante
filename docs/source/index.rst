Covoiturage Daily
================

Application de covoiturage développée en Python selon
une architecture client/serveur et le modèle MVC.

Objectifs
---------

- Gestion des utilisateurs
- Import d'emplois du temps (iCalendar)
- Création automatique de trajets
- Matching conducteur / passager
- Interface graphique PyQt

Architecture
------------

- Client : PyQt5
- Serveur : Flask
- Base de données : SQLite
- Communication : API REST (JSON)
