Réservation
===========

Présentation
------------

Le modèle ``Reservation`` représente une réservation effectuée par un
passager ou reçue par un conducteur.

Il est utilisé pour afficher et gérer les réservations côté client,
sans accès direct à la base de données.

Fonctionnalités principales
---------------------------

- Gestion du nombre de places réservées
- Affichage des informations du trajet
- Suivi du statut de la réservation
- Conversion des données API en objet métier
