InvitationController
====================

Ce module gère la logique des invitations côté client.
Il permet de créer, consulter, accepter ou refuser des invitations
liées aux trajets de covoiturage.

Le contrôleur communique avec l’API serveur via le service ``APIService``
et transforme les réponses JSON en objets métiers ``Invitation``.
