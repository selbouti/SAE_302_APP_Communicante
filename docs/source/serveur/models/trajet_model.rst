Modèle Trajet
=============

Ce module gère les **trajets** dans l’application de covoiturage.

Il permet :
- la création et la suppression de trajets
- la récupération des trajets par utilisateur
- la gestion des modes conducteur / passager
- le calcul des places disponibles
- le matching avancé avec marges horaires

Les requêtes sont exécutées via la classe ``Database``.
