Modèle Profil
=============

Ce module gère l’accès aux données liées au **profil utilisateur**
dans l’application de covoiturage.

Il permet :
- de récupérer les informations personnelles d’un utilisateur
- de mettre à jour ces informations
- de créer ou modifier la voiture associée à un utilisateur

Ce module communique directement avec la base de données
via la classe utilitaire ``Database``.
