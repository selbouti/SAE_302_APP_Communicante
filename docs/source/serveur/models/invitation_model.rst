Modèle Invitation
=================

Ce module gère les **invitations** envoyées par les conducteurs
aux passagers dans l’application.

Il permet :
- de créer une invitation
- de consulter les invitations reçues
- de consulter les invitations envoyées
- d’accepter ou de refuser une invitation

Les invitations sont stockées en base de données et manipulées
via la classe ``InvitationModel``.
