Contrôleur API Voiture
======================

Ce module définit l’ensemble des points d’entrée de l’API liés à la
gestion des véhicules des utilisateurs dans l’application de covoiturage.

Il permet notamment :

- de récupérer la voiture associée à un utilisateur
- de créer ou mettre à jour une voiture
- de supprimer la voiture d’un utilisateur
